# Lecture 01 - Signal Visualization

## Objective

The purpose of this assignment was to create, visualize, and interpret simple signals using MATLAB.

The assignment covered sine waves, frequency, amplitude, noise, saving figures, and responsible use of AI.

---

## Task 1: Create a Sine Wave

A sine wave was generated with:

* Amplitude = 1
* Frequency = 5 Hz
* Duration = 1 second

The signal was plotted in the time domain with a title, axis labels, and grid.

---

## Task 2: Compare Different Frequencies

Three sine waves were generated with frequencies of:

* 2 Hz
* 5 Hz
* 10 Hz

### Which signal changes fastest?

The 10 Hz signal changes fastest because it has the highest frequency.

### Which signal has the lowest frequency?

The 2 Hz signal has the lowest frequency.

### How can you see the difference in the plots?

The difference can be seen by counting the number of cycles in the same amount of time. The 10 Hz signal has more cycles than the 5 Hz signal, while the 2 Hz signal has fewer cycles.

---

## Task 3: Compare Different Amplitudes

Three sine waves were generated with amplitudes:

* 0.5
* 1
* 2

The same frequency of 5 Hz was used for all three signals.

### Which signal has the largest amplitude?

The signal with amplitude 2 has the largest amplitude.

### Does changing amplitude change frequency?

No. Changing amplitude changes the height of the signal but does not change its frequency.

### Give one real-world example where amplitude is important.

Sound volume is one example. A larger amplitude in an audio signal represents a stronger sound signal and is associated with louder sound.

---

## Task 4: Add Noise

A clean 5 Hz sine wave was generated and random noise was added to create a noisy signal.

### What changed after adding noise?

The signal became less smooth and more irregular because random noise was added.

### Can you still recognize the original signal?

Yes. The general sine-wave pattern can still be recognized even though random variations have been added.

### Give one real-world source of signal noise.

Electrical interference from other electronic devices can introduce noise into a signal.
